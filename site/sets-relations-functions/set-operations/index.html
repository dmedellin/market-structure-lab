Set Operations

Five operations, each defined by a connective from course 1. Union is ∨, intersection is ∧, complement is ¬ — which is why the set identities are the logical equivalences wearing different symbols.

Core ideas

What this lesson establishes

Every set operation is a logical connective applied to membership. That correspondence is the reason to have done course 1 first.

1

Union is inclusive

x ∈ A ∪ B when x is in at least one. Elements in both are in the union once — a set has no multiplicities.

2

Complement needs a universe

Ā is meaningless without a stated universal set U. The complement of the even numbers is different inside ℤ and inside ℝ.

3

Difference is not symmetric

A \ B and B \ A are generally different sets. Symmetric difference A △ B is the union of the two, and is the set analogue of ⊕.

The material

The five operations

Definitions, then the correspondence with the connectives.

Definition · Union, intersection, difference

A ∪ B = {x : x ∈ A ∨ x ∈ B}, A ∩ B = {x : x ∈ A ∧ x ∈ B}, A \ B = {x : x ∈ A ∧ x ∉ B}.

Definition · Complement

Relative to a universal set U containing every set under discussion, Ā = U \ A = {x ∈ U : x ∉ A}.

Definition · Symmetric difference

A △ B = (A \ B) ∪ (B \ A) — the elements in exactly one of the two. Equivalently (A ∪ B) \ (A ∩ B).

Definition · Disjoint

A and B are disjoint when A ∩ B = ∅. A collection is pairwise disjoint when every two distinct members of it are disjoint — the condition lesson 8 needs for partitions.

The correspondence with logic

This is not an analogy. Every set identity in lesson 4 is a logical equivalence from course 1 lesson 5, applied pointwise to membership. De Morgan for sets and De Morgan for propositions are the same theorem in two notations, and knowing that halves what has to be memorised.

Theorem · Inclusion-exclusion for two sets

For finite sets, |A ∪ B| = |A| + |B| − |A ∩ B|.

Adding |A| and |B| counts every element of A ∩ B twice — once in each term — and every other element of A ∪ B once. Subtracting |A ∩ B| removes exactly the surplus.

□

Course 4 lesson 10 generalises this to any number of sets, where the alternating signs are less obvious and the correction is larger. The two-set case is worth having by heart now.

Example · Difference is not symmetric

With A = {1, 2, 3} and B = {3, 4}: A \ B = {1, 2} and B \ A = {4}. Their union {1, 2, 4} is A △ B, and A ∩ B = {3} is exactly what △ excludes.

Method

Evaluating a set expression

Translate to membership conditions, then evaluate elementwise.

1

Rewrite the expression as a membership condition

x ∈ A ∩ (B ∪ C) becomes x ∈ A ∧ (x ∈ B ∨ x ∈ C). From here it is propositional logic.

2

Decide the condition for each element in turn

With a small universe this is quick and cannot go wrong. It is also how the lab computes.

3

Watch the universe when complementing

Ā depends entirely on U. An expression mixing complements and an unstated universe is not well defined.

4

Check a boundary case

What does the expression give when A = ∅, or when A = B? Degenerate cases catch misreadings faster than general ones.

Element 4 is the interesting one: it fails the first term and passes the second. Checking a few elements individually is how you catch a misplaced parenthesis, which the set-level calculation hides.

Common mistakes

1
Assuming A \ B = B \ ADifference is not symmetric. A \ B keeps what is in A only; B \ A keeps what is in B only, and those are different sets.
2
Adding cardinalities without subtracting the overlap|A ∪ B| = |A| + |B| holds only when A and B are disjoint. Otherwise the shared elements are counted twice.
3
Complementing without a universeAn expression containing Ā and no stated U is incomplete. The lab pins U = {1, …, 12} for exactly this reason.

Completion standard

✓
Finish when you can translate any set expression into a membership condition without hesitating.

Take (A △ B) \ C and write the condition for x to belong. If you produce (x ∈ A ⊕ x ∈ B) ∧ x ∉ C, the rest of the course's set algebra is course 1 in different symbols.

Note: A △ B is associative and every element is its own inverse under it, which makes the subsets of U a group under symmetric difference. That structure is why △ behaves like addition modulo 2, the same connection ⊕ had in course 1.
