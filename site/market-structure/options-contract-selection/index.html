Lesson 07 · Options

Options contract selection

Translate a directional thesis into a long call or long put deliberately. Compare expiration, moneyness, directional sensitivity, time decay, volatility exposure, and quote quality instead of buying the cheapest contract.

Build a synthetic chain Run the exit simulator
This lab covers long options only

The contract decision stack

Start with the underlying thesis. The option is a wrapper around that thesis, not a substitute for it.

1

Direction

A long call expresses bullish exposure; a long put expresses bearish exposure. Define the chart invalidation first.

2

Time

Expiration must outlast the thesis. Extra time adds premium and changes theta and vega exposure.

3

Strike

Moneyness changes premium, delta, intrinsic value, and how much underlying movement the contract captures.

4

Liquidity

Evaluate the bid/ask spread and actual market depth. A good thesis can be damaged by expensive entry and exit friction.
