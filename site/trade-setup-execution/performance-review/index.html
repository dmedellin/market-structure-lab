Performance review process

Use a stable review cadence and make changes only when the evidence is sufficient for the decision.

1

Validate the journal

Check completeness, sample size, rule consistency, and whether important fields are missing.

2

Calculate core metrics

Review expectancy, win rate, payoff, drawdown, adherence, and execution score.

3

Segment the data

Compare setup, direction, timeframe, regime, mistakes, and followed-plan versus deviated trades.

4

Define one next action

Choose a measurable rule and a fixed next sample before reviewing again.

Review sequence

1
Validate the sampleCheck data completeness, sample size, time period, and whether rules remained consistent.
2
Segment performanceCompare setup, direction, regime, timeframe, adherence, and execution quality.
3
Find one priorityChoose the highest-impact recurring weakness rather than changing everything.
4
Test the changeApply one measurable rule for a defined next sample, then review again.

Common mistakes

1
Changing many variables after one reviewThe next result cannot identify which change helped or hurt.
2
Using aggregate metrics onlyStrong setups can mask weak ones, and disciplined trades can mask costly deviations.
3
Treating a small sample as certaintyPatterns from a few trades should become hypotheses, not permanent rules.
4
Optimizing only for net profitA practical system must also fit drawdown, streaks, execution reliability, and risk limits.
